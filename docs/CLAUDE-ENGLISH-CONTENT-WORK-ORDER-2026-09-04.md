## 목표
현재 한국어 공개 콘텐츠와 영문 콘텐츠를 1:1 대응시켜 영문화율을 높인다. 단순 직역이 아니라 파킨슨병 환자·보호자와 의료인이 자연스럽게 읽을 수 있는 의학 영어로 번역한다. 원문의 개인적 관찰과 임상적 뉘앙스는 보존하되, 관찰과 일반 의학적 사실을 혼동하지 않도록 표현한다.

## 2026-09-04 기준 현황
공개 사용자 콘텐츠 단위를 파일/콘텐츠 항목 기준으로 계산한다.

- 홈: 한국어 1 / 영어 1 — 100%
- 시작 안내: 1 / 1 — 100%
- 용어/증상 이해: 10 / 10 — 100%
- 배우기(강의·교육 글): 24 / 5 — 20.8%
  - 몸으로 쓰는 신경해부학: 한국어 5(서문+1~4부) / 영어 3(서문+1~2부) — 60%
  - 몸으로 쓰는 약리학: 한국어 9(1~6부+특별편 2편+final) / 영어 2(1~2부) — 22.2%
  - 기타 배우기 글: 한국어 10 / 영어 0 — 0%
- 약효일지 사용법 콘텐츠: 8 / 0 — 0%
- 그래프 패턴: 11 / 0 — 0%
- 이야기: 1 / 0 — 0%
- 업데이트 안내: 1 / 0 — 0%

위 공개 콘텐츠 57개를 분모로 잡으면 현재 영어 대응 콘텐츠는 17개, 전체 영문화율은 **29.8% (17/57)**다.

※ 관리자·로그인·프로필·질문게시판의 동적 기능 페이지는 이번 번역률 분모에서 제외한다. 공용 레이아웃/컴포넌트도 콘텐츠 개수 산정에서 제외한다.

## 번역 원칙
- `ON`, `OFF`, `wearing-off`, `delayed ON`, `incomplete ON`, `ON failure`, `dyskinesia`, `dystonia`, `freezing of gait` 등 용어는 기존 `docs/TERMINOLOGY-NOTES.md`, `docs/TERMINOLOGY-VALIDATION.md`, 기존 `src/content/en-terms/` 표현을 우선한다.
- 약물명·용량·시간·수치·날짜는 원문과 대조하여 임의 변경 금지.
- 환자의 체험은 1인칭 관찰로 유지한다. 개인 관찰을 확립된 의학적 인과관계처럼 강화해서 번역하지 않는다.
- 원문에 없는 치료 권고를 새로 추가하지 않는다.
- 자연스러운 미국식 의학 영어를 기본으로 하되 지나치게 학술적으로 바꾸지 않는다.
- 제목, description, SEO metadata도 영어로 작성한다.
- 기존 한국어 파일은 내용 수정 금지. 구조상 꼭 필요한 링크 수정만 허용한다.

## 구현 원칙
- 기존 `src/content/en-learn`, `src/content/en-terms`, `src/pages/en`, `src/layouts/EnBaseLayout.astro` 구조를 최대한 재사용한다.
- 새 영문 콘텐츠는 한국어 slug와 대응 관계를 쉽게 추적할 수 있게 같은 slug를 우선 사용한다.
- 한국어 ↔ English 전환 링크가 가능한 모든 대응 페이지에서 같은 주제의 상대 언어 페이지로 이동해야 한다.
- 번역되지 않은 페이지에서 존재하지 않는 영문 URL로 보내는 링크를 만들지 않는다.
- sitemap에 영문 페이지가 정상 포함되는지 확인한다.
- GA4의 `content_language=en` 추적을 훼손하지 않는다.
