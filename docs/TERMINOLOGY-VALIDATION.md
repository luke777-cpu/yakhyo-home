> **이 문서는 환자용이 아니다.** 사이트 본문에는 이 문서의 내용을 그대로 옮기지 않는다.
> 환자용 표현은 `src/content/understand/*.md`, 검증 이력 요약은 `docs/TERMINOLOGY-NOTES.md`에 있다.

**검증일: 2026-08-21**
**대상: Delayed ON · Incomplete ON · ON Failure · Morning akinesia / Morning OFF**

## 0. 이번 검증에서 무엇을 하지 못했는가 (먼저 읽을 것)

이 검증의 기준은 **원문에서 실제로 확인 가능한 정의**였다.
이 저장소가 도는 실행 환경에서는 **그 기준을 만족시킬 수 없었다.**

2026-08-21 접속 시도 결과 — 아래 도메인이 **전부** egress 프록시에 차단되어 있었다
(HTTP 응답 코드 `000`, 또는 `EGRESS_BLOCKED`):

| 분류 | 도메인 | 결과 |
|---|---|---|
| 1차 색인 | `pubmed.ncbi.nlm.nih.gov`, `pmc.ncbi.nlm.nih.gov`, `ncbi.nlm.nih.gov`, `europepmc.org` | 차단 |
| 학회 | `movementdisorders.org` | 차단 |
| 환자 단체 | `parkinson.org`, `michaeljfox.org`, `apdaparkinson.org`, `parkinsons.org.uk` | 차단 |

사용 가능한 것은 **검색 엔진이 돌려주는 요약 스니펫**뿐이었다.
메타데이터 API조차 막혀 있어 **DOI/PMID가 실제로 어떤 논문을 가리키는지도 확인할 수 없다.**

### 이 문서가 지키는 규칙

작업 지시의 다음 조항을 그대로 적용한다.

> 원문을 직접 열지 못한 자료는 '원문 미확인'으로 명확하게 표시하고,
> **환자용 본문 수정의 근거로 사용하지 말 것.**

따라서 —

1. **참고문헌 목록을 만들지 않았다.** 열어 보지 않은 논문의 제목·저자·연도·DOI를 적으면
   근거가 있는 것처럼 보이게 만들 뿐이다. 이번 검증에서 인용 가능한 문헌은 **0건**이다.
2. **이번에 한 본문 수정은 전부 "주장을 줄이는 방향"뿐이다.** 문헌 없이도 정당한 수정만 했다.
   문헌이 있어야 정당화되는 수정(정의를 새로 쓰거나, 어느 쪽이 맞다고 정하는 일)은 하지 않았다.
3. **아래 표의 판정에 `유지`가 거의 없다.** `유지`는 "문헌으로 확인했고 맞다"는 뜻인데
   이번에 확인한 것이 없으므로 그렇게 적을 수 없다. 대부분 `근거 부족`이다.
   이것은 "우리 문장이 틀렸다"는 뜻이 **아니라** "이 환경에서는 맞는지 확인할 수 없었다"는 뜻이다.

## 2. 다음 사람이 확인해야 할 질문 (문헌 접근이 되는 환경에서)

원문을 열 수 있게 되면 아래를 **이 순서로** 확인하고 이 표의 판정을 갱신한다.
각 항목은 **최소 2개 이상의 독립적인 출처**로 확인하고, 제목·저자·연도·저널·DOI 또는 PMID·**실제 문장**을 이 문서에 남긴다.

| # | 확인할 질문 | 볼 곳 (우선순위 순) |
|---|---|---|
| Q1 | `Delayed ON`이 문헌에서 **하나의 정의로 합의되어 있는가**, 아니면 저자마다 다르게 쓰는가 | MDS 용어/평가척도 문서 → PubMed/PMC 리뷰 → Parkinson's Foundation |
| Q2 | `Delayed ON`에 **시간 기준**(예: 몇 분 이상)이 붙는 정의가 존재하는가. 존재한다면 사이트가 "숫자 기준을 두지 않는다"고 쓰는 것이 적절한가 | 위와 같음 |
| Q3 | `Incomplete ON` / `partial ON` / `suboptimal ON`이 **같은 것을 가리키는가.** 사이트는 `Incomplete ON` 하나만 쓰고 있다 | 위와 같음 |
| Q4 | `ON Failure` / `dose failure` / `no-ON`의 관계. 사이트는 `ON Failure`만 쓴다 | 위와 같음 |
| Q5 | **`Morning akinesia`와 `Morning OFF`가 실제로 다른 것을 가리키는가.** 이전 작업에서 쓴 방향(OFF=첫 복용 전 / akinesia=첫 복용 반응 지연)이 **지지되는가, 반대인가, 아니면 자료마다 다른가** | 위와 같음. **이번에 삭제한 주장이므로 가장 중요하다.** |
| Q6 | 자주 인용되는 wearing-off 정의가 **early-morning akinesia를 포함하는가 제외하는가** | 위와 같음 |
| Q7 | `causes` 항목의 기전 표현(위 배출 지연, 단백질과 흡수의 관계)이 **환자용 페이지에 "가능한 요인"으로 적어도 되는 수준인가** | 위와 같음 |
| Q8 | 유병률 숫자를 환자용에 넣을 수 있는가 (현재는 전부 뺐다) | 위와 같음 |

**Q5가 확인되기 전까지는 사이트 본문에서 두 용어의 방향을 다시 지정하지 않는다.**

## 3. 이번에 근거가 없어 **손대지 않은** 문장

주장을 줄이는 수정만 했으므로, 다음은 그대로 두었다.
"맞다고 확인했다"는 뜻이 아니라 **"문헌 없이 고치면 더 나빠진다"**고 판단한 것이다.

- 네 글의 `definition:` 한 줄 (4건). → 대신 사이트 차원에서 "형식적 정의가 아님"을 명시.
- `causes:` 의 기전 관련 항목 전부. → 이미 "~수 있습니다" + 섹션 안내문으로 두 겹 완화되어 있음. Q7에서 재검토.
- `expressions:` (환자 표현 예시). → 의학적 주장이 아님.
- `record:` / `forVisit:` 항목. → 기록 방법에 대한 안내이지 의학적 정의가 아님.
- `graphs/` 컬렉션 11편. → 이번 검증 범위 밖(그래프 읽는 법). 용어 정의를 새로 주장하는 문장이 있는지는 다음 회차에서 훑을 것.

## 4. 이번에 하지 않은 것 (지시 7항)

새 영상 · Q&A 구현 · Vercel/Supabase 작업 · 새 대규모 페이지 · 새 용어 정의 · 개인 경험 기반 의학적 확정 — **전부 하지 않았다.**
새 UI 컴포넌트도 만들지 않았다. 수정은 기존 마크다운 본문과 기존 `Callout` 안의 텍스트뿐이다.
